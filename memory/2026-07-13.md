# 2026-07-13 KRL 函数签名分析 (续)

## KRL 函数签名 (从源码确认)

### 核心运动
- **PNT_LIN**(x, y, z, a, b, c, e_val, vel) — 打印轨迹插补, 速度 mm/s → KUKA 内部转 m/s
- **PNT_G0**(x, y, z, a, b, c, vel) — 空行程(无挤出), 速度 mm/s
- **PNT_G92_E0**() — E轴虚拟归零 (G92 E0)
- **PNT_RETRACT**() / **PNT_UNRETRACT**() — 回抽/恢复
- **PNT_CIRC** — 未在 PNT_CORE 中找到，弧形由 LIN 小线段近似 (C_DIS C_VEL)

### 系统管理
- **PNT_INIT**() — 系统初始化 (关加热/风扇，配置E1轴，$ADVANCE=3)
- **PNT_FINISH**() — 打印结束 (停挤出，关加热，风扇延时30秒)
- **PNT_ABORT**(reason) — 中止 (BRAKE，关加热)
- **PNT_PAUSE**() / **PNT_RESUME**() — 暂停/恢复

### 温度/辅助
- **PNT_HEAT_ON**(zone, temp) / **PNT_HEAT_OFF**(zone)
- **PNT_HEAT_ALL**(t1..t6) / **PNT_HEAT_WAIT_ALL**(timeout_ms)
- **PNT_FAN_ON**() / **PNT_FAN_OFF**() / **PNT_FAN_SET**(speed)

### 高级参数 (已预留，TODO实现)
- PNT_SET_MAX_ACCEL / PNT_SET_MAX_FEEDRATE / PNT_SET_JERK / PNT_SET_PRESSURE_ADVANCE
- PNT_DWELL(ms) — G4 延时

### KUKA 系统设定
- 工具: $TOOL = TOOL_DATA[1] (默认 Tool 1)
- 基座标: $BASE = BASE_DATA[1] (默认 Base 1)
- 预进指针: $ADVANCE = 3 (最大预读)
- E1轴速度: $VEL_EXTAX[1], 加速度: $ACC_EXTAX[1]

## 关于 Klipper 格式

### Klipper vs Marlin G-code 对比
| 特性 | Marlin | Klipper | 对 KRL 后处理的影响 |
|------|--------|---------|---------------------|
| 运动指令 | G0/G1 X Y Z E F | 同 | ✅ 完全相同 |
| 温度设置 | M104 S200 | SET_HEATER_TEMPERATURE HEATER=extruder TARGET=200 | ⚠️ 需额外解析 |
| 热床 | M140 S60 | SET_HEATER_TEMPERATURE HEATER=heater_bed TARGET=60 | ❌ 无热床，忽略 |
| 加速度 | M204 S1000 | SET_VELOCITY_LIMIT ACCEL=1000 | ❌ KRL用$VEL控制 |
| 回抽 | G1 E- | G10 (firmware retract) | ⚠️ 不同命令 |
| 压力提前 | M572 S0.05 | SET_PRESSURE_ADVANCE ADVANCE=0.05 | ⚠️ 可映射到PNT_SET_PRESSURE_ADVANCE |
| 速度钳制 | SET_VELOCITY_LIMIT | ✅ 更清晰 | ✅ 用Klipper更好 |

### 推荐: 使用 Klipper flavor
优点:
1. 运动指令完全一样，解析无差异
2. 加速度用 SET_VELOCITY_LIMIT 语义更清晰
3. Klipper 是 OrcaSlicer 原生支持的现代 flavor
4. 压力提前可映射到 KRL 预留接口

需要额外解析的命令 (vs Marlin):
- `SET_HEATER_TEMPERATURE HEATER=extruder TARGET=200` → `PNT_HEAT_ON(1, 200)`
- `SET_VELOCITY_LIMIT ACCEL=1000` → 跳过 (KRL用$VEL_CP)
- `SET_PRESSURE_ADVANCE ADVANCE=0.05` → `PNT_SET_PRESSURE_ADVANCE(0.05)` (可选)

### G-code → KRL 完整映射表 (Klipper flavor)

#### 运动类
| G-code | KRL |
|--------|-----|
| G90 | (忽略，KRL 默认绝对坐标) |
| G21 | (忽略) |
| M82/M83 | (跟踪状态，影响E值解析) |
| G1 X Y Z E F (extrude) | PNT_LIN(X, Y, Z, 0, 0, 0, E, F_mm_s) |
| G1 X Y Z F (travel) | PNT_G0(X, Y, Z, 0, 0, 0, F_mm_s) |
| G1 X Y E F (extrude, no Z) | PNT_LIN(X, Y, current_Z, 0, 0, 0, E, F_mm_s) |
| G1 X Y F (travel, no Z) | PNT_G0(X, Y, current_Z, 0, 0, 0, F_mm_s) |
| G92 E0 | PNT_G92_E0() |
| G1 E- (retract) | PNT_RETRACT() |
| G1 E+ (unretract) | PNT_UNRETRACT() |
| G4 P{ms} | PNT_DWELL({ms}) |

#### 温度类
| Klipper G-code | KRL |
|----------------|-----|
| SET_HEATER_TEMPERATURE HEATER=extruder TARGET=200 | PNT_HEAT_ON(1, 200) |
| M109 S200 (wait for temp in Marlin compat) | PNT_HEAT_WAIT(1, 180000) |
| SET_HEATER_TEMPERATURE HEATER=heater_bed TARGET=60 | (忽略, 无热床) |

#### 风扇类
| G-code | KRL |
|--------|-----|
| M106 S255 | PNT_FAN_ON() 或 PNT_FAN_SET(255) |
| M106 S0 | PNT_FAN_OFF() |

#### 加速度/压力提前类
| Klipper G-code | KRL |
|----------------|-----|
| SET_VELOCITY_LIMIT ACCEL=1000 | (忽略, KRL用$VEL_CP) |
| SET_PRESSURE_ADVANCE ADVANCE=0.05 | PNT_SET_PRESSURE_ADVANCE(0.05) (可选) |

#### 程序结构
| 位置 | KRL |
|------|-----|
| 文件头 | `DEF <jobname>()` + EXT声明 |
| 开始 | PNT_INIT() |
| 预热 | PNT_HEAT_ALL(...); PNT_HEAT_WAIT_ALL(180000) |
| 打印前 | PNT_G92_E0(); PNT_UNRETRACT() |
| 层切换 | PNT_G92_E0(); PNT_RETRACT(); PNT_G0(...); PNT_UNRETRACT() |
| 每段注释 | `;TYPE:WALL-OUTER` → 保留为 KRL 注释 |
| 结束 | PNT_RETRACT(); PNT_FAN_OFF(); PNT_HEAT_ALL(0,0,0,0,0,0); PNT_FINISH() |
| 文件尾 | `END` |

### 速度转换注意
- G-code F = mm/min → KRL vel 参数 = mm/s
- 例: G1 F3600 → PNT_LIN(..., 60.0)  // 3600÷60 = 60 mm/s

### 输出文件格式
- 文件名: {jobname}.SRC (KUKA 标准扩展名，大写)
- 编码: UTF-8 (KUKA 兼容)
- 结构: DEF ... END 包裹
